# Sound effects

All files here are CC0 (public domain): free for commercial use, no credit
required (we credit them anyway in CREDITS.txt). Chosen 2026-10-05 (Q67, option 1).
They were cut, de-hissed and levelled by `scripts/convert-sfx.ps1` from the
sources below, downloaded as Freesound HQ previews and Kenney pack zips. Run the
Godot import step after changing them. No AI-generated audio is used here.
