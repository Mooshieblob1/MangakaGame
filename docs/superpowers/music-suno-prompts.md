## How to generate

Updated 2026-09-28 for the built music system: tracks play once, then 60 to
120 seconds of quiet follow, so they do not need to loop.

- **Plan:** a paid Suno plan with commercial rights. Suno has said songs made on
  the free plan are not covered by a later upgrade; confirm in its current terms
  on the day you generate.
- **Settings:** Custom mode, **Instrumental** on, the cue's prompt in the style
  box, the lyrics box empty. If your version has an **Exclude styles** box, put
  `vocals, singing, rap, spoken word, vocal chops` in it.
- **Length:** 2 to 3 minutes for title, day, night and studio cues; 1 to 2
  minutes is ideal for the event cues (convention, deadline, good news,
  setback), since they cut in and play once. Longer takes still work.
- **Choosing a take:** each generation gives two; keep the better one. Reject
  takes with any vocals or vocal chops, sudden loud drops or build-ups, a long
  silent or very quiet intro (more than about 3 seconds), or an abrupt cut-off at
  the end. A gentle ending or fade-out is good. The title track restarts in the
  menu, so an ending that leads back to its opening is a bonus.
- **Download:** WAV if your plan allows it, otherwise MP3.
- **Naming:** name each file after its cue, for example `day-01.wav`. Extra
  takes you like can become more tracks: `day-05.wav`, `night-03.wav` and so on
  join the same pools automatically.
- **Where:** save the downloads in any folder outside the repository (for
  example `Downloads\mangaka-music`) and tell me; I convert them with
  `scripts/convert-music.ps1` (see "Adding tracks to the game").
- **Record:** note the plan, date and any prompt changes in the provenance table
  at the end, or just tell me.

The prompts lean towards dusty, jazzy late-1990s Japanese jazz-hop textures so
the lo-fi sound still sits comfortably in 1996 Tokyo.

## Adding tracks to the game

1. Name each download after its cue (for example `day-01.wav`).
2. Run `scripts/convert-music.ps1 -Source <download folder>`. It writes
   loudness-matched OGG files to `godot/Assets/Music/`. Only those OGG files are
   committed; keep the downloads outside the repository.
3. Run the Godot import step, then start the game. Tracks are found by name.
4. Fill in the provenance table above, and add the credits line to
   `docs/superpowers/private-alpha-credits.txt` with the first real track:
   "Music: AI-generated with Suno (see docs/superpowers/music-suno-prompts.md)."
