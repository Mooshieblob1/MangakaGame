# Music: Suno prompts

Date: 2026-09-26. Direction: modern lo-fi "study beats" (Tier 2 question 2,
option 2), generated by the user in Suno. See the
[considerations](specs/2026-09-26-early-access-considerations.md).

## How to generate

- Use Custom mode, switch on **Instrumental**, paste the prompt into the style
  box and leave the lyrics box empty.
- Generate on a paid plan with commercial rights. Suno has said songs made on
  the free plan are not covered by a later upgrade; confirm in its current terms.
- Aim for 2 to 3 minutes. Each generation gives two takes; keep the best one.
  Reject takes with vocals, vocal chops, sudden drops or a fade-in longer than
  a few seconds, since tracks will loop and crossfade in the game.
- Download as WAV if your plan allows it, otherwise MP3. Converting to the
  game's format is my job.
- Save files to `godot/Assets/Music/` using the file names below, and note the
  plan, date and final prompt for each in the provenance table at the end.

The prompts lean towards dusty, jazzy late-1990s Japanese jazz-hop textures so
the lo-fi sound still sits comfortably in 1996 Tokyo.

## Adding tracks to the game

1. Name each download after its cue (for example `day-01.wav`).
2. Run `scripts/convert-music.ps1 -Source <download folder>`. It writes
   loudness-matched OGG files to `godot/Assets/Music/`. Only those OGG files are
   committed; keep the downloads outside the repository.
3. Run the Godot import step, then start the game. Tracks are found by name.
4. Fill in the provenance table above, and add the credits line to
   `docs/superpowers/private-alpha-credits.txt` with the first real track:
   "Music: AI-generated with Suno (see docs/superpowers/music-suno-prompts.md)."
